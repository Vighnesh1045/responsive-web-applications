## 📊 Featured Projects & Applications

### 1. 🔤 Decimal to Roman Converter (`decimalToRoman/`)
* **Description:** An interactive web utility that converts standard decimal numbers into their corresponding Roman numerals with robust input validation.
* **Tech Stack:** HTML5, CSS3, Vanilla JavaScript (DOM manipulation and algorithm design).

### 2. 🔄 Palindrome Checker (`palindromeChecker/`)
* **Description:** A text-analysis tool that validates whether a given word, phrase, or sentence reads the same backward as forward (automatically handling edge cases like punctuation, spaces, and case sensitivity).
* **Tech Stack:** HTML5, CSS3, JavaScript (Regular expressions and string parsing).

### 3. 📈 Spreadsheet Application (`spreadSheet/`)
* **Description:** A functional mini-spreadsheet interface allowing users to input data, execute cell operations, and compute dynamic formula evaluations.
* **Tech Stack:** HTML5, CSS3, Advanced JavaScript (Grid layout, event listeners, and custom calculation logic).

### 4. 🧮 Statistic Calculator (`statisticCalculator/`)
* **Description:** A data analytics utility designed to instantly compute core statistical metrics (such as mean, median, mode, range, variance, and standard deviation) from raw numerical datasets.
* **Tech Stack:** HTML5, CSS3, JavaScript (Statistical math formulas and dynamic DOM updates).

## 🚀 Running Locally

To run or test any of these projects locally on your machine:

1. **Clone the repository:**
```bash
git clone [https://github.com/Vighnesh1045/WebDevelopment.git](https://github.com/Vighnesh1045/WebDevelopment.git)

```


2. **Navigate into a specific project folder:**
```bash
cd WebDevelopment/decimalToRoman

```


3. **Launch the application:**
* Double-click `index.html` to open it in any web browser, **OR**
* Open the project directory in **VS Code** and use the **Live Server** extension.
